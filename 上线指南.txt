小团·陪伴 — 发布成手机 App（APK 直发版，零基础流程）
==================================================

目标：让别人能在手机上「下载安装」你的 App，你用管理员账号登录后台看数据。
本方案不需要你懂代码、不需要填任何密钥、不需要 App Store 审核。
你只需做几件「用鼠标点一点」的事，全程约 20–30 分钟。

整体思路：
  ① 把代码传到 GitHub（免费账号，网页拖拽即可）
  ② 一键部署到 Render，拿到一个 https 网址（你的 App 就住在这里）
  ③ 用微软免费工具 PWABuilder，把该网址一键转成安卓安装包 .apk
  ④ 把 .apk 放回项目重新部署，别人点链接/扫码就能下载安装
  （iPhone 用户用 Safari「添加到主屏幕」即可，功能一样）

────────────────────────────────
第 1 步：注册两个免费账号（邮箱即可）
────────────────────────────────
• GitHub：https://github.com  → 注册（用来存放代码，免费）
• Render：https://render.com  → 注册（用来运行你的 App，免费）
都用同一个邮箱注册即可，全程免费。

────────────────────────────────
第 2 步：把代码传到 GitHub（网页操作，不用装任何软件）
────────────────────────────────
1. 打开 GitHub（你已注册：fxq945000-creator），点右上角 “+” → “New repository” → 名字填 xiaotuan → 选 Public → 创建。
   创建后你的仓库地址就是：https://github.com/fxq945000-creator/xiaotuan
2. 进到新仓库，点 “uploading an existing file” / “add file → upload files”。
3. 把你电脑里 companion-app 文件夹里的【所有文件】一起拖进上传区（按住文件夹拖进去即可）。
4. 拉到底点 “Commit changes” 提交。现在代码已经在网上了。

────────────────────────────────
第 3 步：一键部署，拿到 https 网址（最关键）
────────────────────────────────
做法 A（最省事，推荐）：
  打开下面这个链接（已替你填好账号，仓库名用 xiaotuan；若你改名需同步修改）：
  https://render.com/deploy?repo=https://github.com/fxq945000-creator/xiaotuan
  页面会自动读入配置，点 “Create Web Service” 即可。
做法 B：
  登录 Render → New → Web Service → 关联刚才的 GitHub 仓库 → 它会自动识别 render.yaml。
  Build Command 留空，Start Command 自动是 node server.js → 创建。

等 1–2 分钟部署完成，Render 会给你一个网址，形如：
  https://xiaotuan.onrender.com
这就是你 App 的“家”。记下来（后面要用）。

（可选）指定管理员：在 Render 的 Environment 里加 ADMIN_EMAIL=你的邮箱，
则该邮箱无论第几个注册都会是管理员；不填则第一个注册的是管理员。

────────────────────────────────
第 4 步：手机注册管理员 + 进后台
────────────────────────────────
1. 手机浏览器打开你的网址 https://xiaotuan.onrender.com
2. 用邮箱注册一个账号 ——【第一个注册的自动成为管理员】。
3. 后台地址：https://xiaotuan.onrender.com/admin
   用同一邮箱登录，即可看到用户/宠物数据、处理反馈、发公告、调倍率。

────────────────────────────────
第 5 步：用 PWABuilder 生成安卓安装包 .apk（免费）
────────────────────────────────
1. 电脑浏览器打开 https://pwabuilder.com
2. 输入你的网址 https://xiaotuan.onrender.com → 点 “Start”
3. 看到 “Android” 卡片 → 点 “Generate” → 等一会儿
4. 选 “Download” 下载 .apk 安装包到电脑（建议改名 app-release.apk）
就这么简单，你已经有了可以安装的安卓包。

────────────────────────────────
第 6 步：让“别人”能下载安装（二选一）
────────────────────────────────
方式一 · 放在同一个网址里（推荐，不用额外平台）
  1. 把第 5 步下载的 app-release.apk 放进 companion-app 文件夹。
  2. 按第 2 步的方式，把它上传/更新到 GitHub 仓库，Render 会自动重新部署。
  3. 别人打开 https://xiaotuan.onrender.com/download.html
     → 点「安卓：下载安装包」即可下载安装（页面还有二维码可分享）。

方式二 · 放 GitHub Releases（包较大时更稳）
  1. GitHub 仓库 → Releases → Draft a new release → 把 app-release.apk 传上去发布。
  2. 复制该 .apk 的下载链接，打开 download.html 顶部，把 CFG.apk 改成这个链接，
     重新上传 download.html 到 GitHub 即可。

安卓安装时若提示“未知来源”，在手机设置里允许“允许来自此来源的应用”即可。

────────────────────────────────
iPhone 用户怎么用？
────────────────────────────────
iOS 暂不支持直接装 .apk。让 iPhone 用户用 Safari 打开你的网址 → 点底部“分享”
→ “添加到主屏幕”，桌面会出现「小团」图标，点开即全屏 App，功能与安卓一致。
（download.html 里已内置 iPhone 安装教程按钮，直接转发该页即可。）

────────────────────────────────
⚠️ 一个重要提醒：数据会不会丢？
────────────────────────────────
免费版 Render 在每次重新部署/长时间无访问时会重启，可能清空数据文件
（companion-app/data/store.json），也就是用户进度和管理员看到的数据会重置。
• 个人小范围试用：无所谓，重置后重新注册即可。
• 正式给很多人用：建议二选一：
  A. 在 Render 升级到付费 Starter 计划（约 $7/月），并在 Environment 加一块 Disk
     挂载到 /data，再把环境变量 DATA_DIR 设为 /data —— 数据就永久保存。
  B. 改用 Railway / Koyeb 等自带免费持久盘的节点（步骤类似，搜“Railway 部署 Node”）。

────────────────────────────────
管理后台能做什么（/admin）
────────────────────────────────
• 数据看板：用户数、今日活跃、有效会员、累计充值、宠物阶段分布
• 用户与宠物：按 UID/昵称/邮箱搜索，看某用户宠物状态，封禁/解封
• 充值/会员：给指定用户补偿或扣减星星币
• 客服工单：查看用户反馈、回复并改状态
• 运营配置：调成长倍率、开关补偿、发布公告

────────────────────────────────
常见问题
────────────────────────────────
Q：手机打开网址一片白？
A：确认网址是 https 开头；用电脑先打开看有没有报错；检查 Render 部署是否 “Live”。
Q：安装包装不上？
A：安卓需允许“未知来源”；iPhone 请走“添加到主屏幕”，不要直接下 .apk。
Q：想换自己的图标/名字？
A：改 manifest.webmanifest 的 name/short_name，替换 icon-*.png 后重新部署。
Q：国内访问 Render 有点慢？
A：可改用 Koyeb/Railway（节点更近）；或以后买台轻量云服务器自行部署（我可给脚本）。

需要我继续做的话，可以：① 在 App 里加“意见反馈”按钮（已预留接口）；
② 给你一份可直接点部署的 Dockerfile / 国内云脚本；③ 接入真实收款。
